# Упрощенный интерфейс ECAM с переключением вертолетов

## Что было сделано:

### 1. **Добавлена система переключения между вертолетами**
- Добавлены Q_PROPERTY в `dataread.h`:
  - `aircraftSelection` - текущий выбранный вертолет (1 или 2)
  - `currentAircraftName` - название текущего вертолета ("Вертолет 1" или "Вертолет 2")
- Метод `setAircraftSelection(int)` теперь испускает сигнал `aircraftSelectionChanged()`

### 2. **Создан максимально простой интерфейс**
Интерфейс состоит из:
- Панели переключения вертолетов (2 кнопки + отображение текущего)
- 6 простых блоков с данными:
  1. Батарея (напряжение и ток)
  2. Двигатель (RPM и температура)
  3. Температуры (КПП и AGI)
  4. Скорости вращения (КПП и ротор)
  5. Статусы системы (черный ящик, сервопривод, передача)
  6. Пользовательские переменные U1-U3

### 3. **Как работает переключение данных**
При нажатии кнопки "Вертолет 1" или "Вертолет 2":
1. Вызывается `pb.setAircraftSelection(1)` или `pb.setAircraftSelection(2)`
2. В C++ коде устанавливается `m_aircraftSelection`
3. Все QML элементы автоматически обновляются, показывая данные из соответствующего объекта:
   - `report` - данные для вертолета 1
   - `report2` - данные для вертолета 2

## Как использовать:

### Запуск приложения:
```bash
./ECAMGCU9
```

### Переключение вертолетов в интерфейсе:
1. Нажмите кнопку **"Вертолет 1"** - показываются данные из первого объекта `report`
2. Нажмите кнопку **"Вертолет 2"** - показываются данные из второго объекта `report2`

### Данные, которые переключаются:
- Все основные параметры системы (батарея, двигатель)
- Температуры и скорости вращения
- Статусы системы
- Пользовательские переменные U1-U14, W1-W7, F1-F9, C1-C3, B1-B4

## Файлы интерфейсов:

1. **`main.qml`** - текущий упрощенный интерфейс (600x400)
2. **`main_simple.qml`** - более подробный интерфейс (1024x768)
3. **`main_simple_ver2.qml`** - средний вариант (800x600)
4. **`main_minimal.qml`** - самый минимальный вариант

## Чтобы изменить интерфейс:
1. Скопируйте содержимое нужного файла в `main.qml`
2. Перекомпилируйте проект: `make clean && make`
3. Запустите: `./ECAMGCU9`

## Ключевые преимущества:
- Максимально простой и понятный интерфейс
- Мгновенное переключение между вертолетами
- Все данные автоматически обновляются при переключении
- Минимальное использование ресурсов
- Простая навигация - всего 2 кнопки для переключения
